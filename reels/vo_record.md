# نص التسجيل (sawty – Puck)

كل ريل في ملف واحد، والسطور بالترتيب. **سيب سكتة واضحة (نص ثانية أو أكتر) بين كل سطر والتاني**، عشان `split_vo.py` بيقسّم على السكتات دي.
النقط بتعمل وقفة جوه السطر. احفظ كل ملف باسم الـ id في `reels/vo/`.

لو هتسجّل صوتين (يوسف ويسوع)، سجّل كل سطر بصوته، وبعدين اجمع الأربع سطور بالترتيب في ملف واحد.

---

## reel4_only_in_trouble — لما بيبقى عندي مشكلة بس
```
يُوسِف: يَا رَبّ… أَنَا مَكْسُوف مِنَّك… مَبَجِيش أَكَلِّمَك غِير لَمَّا أَكُون فِي مُشْكِلَة… لَمَّا بَبْقَى كْوَيِّس بَنْسَاك… وَلَمَّا الدُّنْيَا تِقْفِل فِي وِشِّي… أَجْرِي عَلِيك.

يَسُوع: وَأَنَا فَرْحَان إِنَّك هِنَا.

يُوسِف: يَعْنِي أَنَا… مِش وِحِش؟

يَسُوع: لَأ….. أَنَا اللِّي قُلْتِلَك تِيجِي وَقْت الضِّيق… «اُدْعُنِي فِي يَوْمِ الضِّيقِ….. أُنْقِذْكَ.»
```

## reel1_loneliness — الوحدة
```
يُوسِف: يَا رَبّ….. أَنَا وَسْط كُلّ النَّاس دِي… وِمَحَدِّش حَاسِس بِيَّا… بَكَلِّم نَاس طُول الْيُوم… وِمَحَدِّش فِيهُم بِيِسْأَلْنِي… إِنْتَ عَامِل إِيه بِجَدّ.

يَسُوع: أَنَا سَامْعَك… وَأَنَا بَسْأَلَك… إِنْتَ عَامِل إِيه؟

يُوسِف: بِجَدّ؟… طَب لِيه دَايْمًا حَاسِس إِنِّي لِوَحْدِي؟

يَسُوع: عَشَان مِسْتَنِّي النَّاس تِمْلَا مَكَان… أَنَا بَسّ اللِّي أَقْدَر أَمْلَاه… وَأَنَا قُلْتِلَك… «لَا أُهْمِلُكَ… وَلَا أَتْرُكُكَ.»
```

## reel2_tired — التعب
```
يُوسِف: يَا رَبّ أَنَا تْعِبْت… بَصْحَى بَدْرِي وِبَرْجَع آخِر اللِّيل… وِالْفِلُوس بِتِخْلَص قَبْل الشَّهْر مَا يِخْلَص… وِحَاسِس إِنِّي مِش مِلَاحِق عَلَى حَاجَة.

يَسُوع: تَعَالَى… اُقْعُد جَنْبِي شُوَيَّة.

يُوسِف: طَب وِكُلّ اللِّي وَرَايَا دَه… مِين هَيْشِيلُه؟

يَسُوع: مِش لَازِم تِشِيلُه لِوَحْدَك… «تَعَالَوْا إِلَيَّ يَا جَمِيعَ الْمُتْعَبِينَ وَالثَّقِيلِي الأَحْمَالِ….. وَأَنَا أُرِيحُكُمْ.»
```

## reel3_guilt — الذنب
```
يُوسِف: يَا رَبّ أَنَا وَعَدْتَك إِنِّي مِش هَعْمِلْهَا تَانِي….. وِعْمِلْتَهَا… كُلّ مَرَّة أَقُول دِي آخِر مَرَّة… وَأَرْجَع أَقَع… أَنَا مَكْسُوف أَكَلِّمَك أَصْلًا.

يَسُوع: بُصِّلِي… أَنَا لِسَّه هِنَا.

يُوسِف: يَعْنِي إِنْتَ… مِش زَعْلَان مِنِّي؟

يَسُوع: أَنَا زَعْلَان عَلِيك… مِش مِنَّك… «إِنِ اعْتَرَفْنَا بِخَطَايَانَا فَهُوَ أَمِينٌ وَعَادِلٌ….. حَتَّى يَغْفِرَ لَنَا خَطَايَانَا.»
```

## reel5_ashamed_to_return — مكسوف أرجع
```
يُوسِف: يَا رَبّ….. بَقَالِي كْتِير مَصَلِّتْش… مِش عَارِف أَبْدَأ مِنِين… وَلَا أَقُول إِيه… حَاسِس إِنِّي بْعِدْت أَوِي.

يَسُوع: مَا إِنْتَ بَدَأْت دِلْوَقْتِي.

يُوسِف: بَسّ هُوَّ يِنْفَع أَرْجَع… بِالسُّهُولَة دِي؟

يَسُوع: الْبَاب عُمْرُه مَا اتْقَفَل… «مَنْ يُقْبِلْ إِلَيَّ….. لَا أُخْرِجْهُ خَارِجًا.»
```

## reel6_forget_when_good — بنساك لما ببقى كويس
```
يُوسِف: يَا رَبّ أَنَا لَمَّا بَبْقَى مَبْسُوط بَنْسَاك خَالِص… مَبَصَلِّيش… وِمَبَفْتِكْرَكْش… وِبَعْدِين أَتْضَايِق مِن نَفْسِي.

يَسُوع: بَسّ أَنَا… مَبَنْسَاكْش.

يُوسِف: إِزَّاي؟… إِزَّاي لِسَّه بِتِسْتَحْمِلْنِي؟

يَسُوع: عَشَان إِنْتَ غَالِي عَنْدِي… «هُوَذَا عَلَى كَفَّيَّ….. نَقَشْتُكِ.»
```

> متكتبش «يُوسِف:» و«يَسُوع:» في التسجيل نفسه، دول عشان تعرف مين بيتكلم بس.
